# Changelog

## 1.0.1

- Colors adapt to light and dark mode. In light mode the unfocused tracks were nearly
  invisible, and in dark mode the focused background was darker than the screen behind it.
- The example app has a `-showcase` mode and a UI test that captures the README screenshots.

## 1.0.0

- Initial release: focusable `TVSlider` and `TVStepper` for tvOS with D-pad acceleration,
  touch-surface scrubbing and accessibility; native fallbacks elsewhere; `SliderModel`.
